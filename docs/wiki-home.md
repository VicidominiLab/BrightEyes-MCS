# BrightEyes-MCS documentation

BrightEyes-MCS documentation is maintained with the source code. Start with the
[repository documentation index](https://github.com/VicidominiLab/BrightEyes-MCS/blob/HEAD/docs/README.md)
for installation, user guides, developer instructions, and technical references.
Select the branch or release matching your installation before following a guide.

Older Wiki pages and diagrams may describe previous releases. Use the versioned
guides for current commands, package names, and supported workflows.
